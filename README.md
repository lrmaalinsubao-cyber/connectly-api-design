# connectly-api-design# Connectly API Design

This repository contains the system design diagrams for the Connectly API.

## Diagrams Included
- Entity Relationship Diagram (ERD)
- CRUD Interaction Flow
- System Architecture Diagram
- Authentication Flow Diagram

## Description
Connectly is a simple social platform API where users can create posts, like posts, and comment on posts. Authentication is handled through Google OAuth.
